## 地图结论

运行 `PYTHONPATH=src python -B scripts/audit_phase7_map.py`，原始结果 [phase7-map.json](experiments/phase7-map.json)。342节点、768有向边；180条有向边无反向伙伴，保留原数据真实单向关系，没有为演示补反向边。全部边几何首尾与对应路由节点一致。图 validate 与14项校园/OSM回归通过。

五个seed 0、1、42、100、2026道路完整指纹相同，初始区域配额均为校内20、周边4。30候选地点固定为校内22、周边8。参考点、道路服务锚点、snap距离、OSM引用、名称、来源与近似标记逐项保存在原始核验JSON；节点与标签使用同一ID。

游泳馆北侧快递站来自用户描述；四门外卖柜来自用户确认的校门参考位置及配置偏移，均未实地测绘。宿舍/教学楼/图书馆参考OSM建筑，服务点锚定附近可达道路，不把建筑中心或校门坐标冒充柜位/楼门。UI点选显示近似服务点及 location_note。仓库与周边配送地点属于模拟设施/固定候选池。

离线OSM原件、派生数据与配置SHA256均保存在核验JSON。数据及旧实验未改动。背景建筑、步道及底图道路只供展示；规划和动画只使用当前图中有向边的geometry。端点核验不能证明现实门禁/转向限制或建筑轮廓最新；本轮未增加实地测绘或实时导航保证。

数据源 OpenStreetMap，保留 source_url、下载日期、原件hash及 ODbL 许可；本轮无外部抓取。更早来源与构造说明继续见 [校园报告](bjut-campus-delivery.md)。

36单被明确拒绝：初始无放回候选池仅30个；没有为了凑规模生成非法场景或修改容量/客户池。12单使用合法10/2区域配额，24单保留20/4。两个有效规模的初始两目标均独立完整验证。

装货后请求暂停，仅完成已进入原子装货动作，原货物保留；step分别0.000041/0.000087秒。随后动态新增特急单，重规划分别0.0511/0.1849秒。12单续程完整；24单续程安全但部分，新单因 completion_deadline 未接纳，原24单继续配送。未伪称25单全覆盖。执行历史独立审计分别0.00070/0.00513秒，均valid，24单规模因仍有新单待处理而complete_all=false。

未发现需要改变核心算法的严重耗时；因此本轮**没有实施性能优化或改变贪心逻辑**。约0.71MB快照包含不变底图，仍有将来按版本拆分静态地图的空间；本轮不为此引入第二套协议。浏览器渲染及重渲染实际观测另见最终视觉记录，不把接口耗时称为浏览器帧率。
